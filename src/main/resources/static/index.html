Остатки

—
Ручки GET /store/stock нет — таблица собирается из витрины GET /brand/{brandId}/products (brandId берётся из токена магазина) и отфильтрована по своему storeId.

Что реально есть в API

Собрано по контроллерам ветки refactor/store-model. Context-path — /api/v1, все ответы завёрнуты в ApiResponse { success, data, error, stats }, поэтому в таблице указано содержимое data.

Чего не хватает на бэкенде

Всё, что помечено demo на странице, работает на локальных заглушках, потому что ручки нет или она сломана. Зелёным — то, что закрыто с прошлого прохода.

Лог запросов

Страница лежит в src/main/resources/static/index.html и раздаётся самим Spring — открывай http://localhost:8080/api/v1/, тогда нет проблем с CORS. Если открыть файл напрямую (file://), браузер зарубит все запросы: CORS в проекте не настроен.
